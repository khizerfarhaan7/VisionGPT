# VisionGPT Documentation

This folder contains the project's documentation, schemas, architectural diagrams, and guidelines.

## Folder Directory
- `docs/`: System documentation, user flows, API schemas.
- `frontend/`: Next.js 15 app router, Tailwind CSS, TypeScript, shadcn/ui components.
- `backend/`: FastAPI Python 3.12 server using SQLAlchemy 2.0 async connections.
- `uploads/`: Placeholders for local media/file uploads (dev storage).
- `database/`: Database configuration and migration scripts (Alembic).
